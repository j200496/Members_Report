# Members-Report

## 📌 Overview

This app is built to upload data from an excel file and the app creates a complete dashboard panel dividing the members per age, gender, users etc

## 🚀 Tech Stack
- **python:** streamlit. pandas, matplot lib

## ⚙️ How to Run Locally
1. Clone the repo: `git clone [url]`
2. Setup: `dotnet pip install -r requirements.txt
`, `streamlit run app.py
`
